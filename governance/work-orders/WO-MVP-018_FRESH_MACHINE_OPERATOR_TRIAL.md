# WO-MVP-018 — Fresh-Machine Operator Trial and Deployment Rehearsal

Status: IMPLEMENTED

## Objective

Provide a repeatable operator-controlled process that installs the Platform against an explicit local Core checkout, performs diagnostics, verifies launch readiness, exercises governed behavior, optionally verifies release trust, records timing and friction, and emits a machine-readable acceptance record.

## Acceptance evidence

- deterministic analysis-only, completed, paused, denied, and failed scenarios;
- occupied-port readiness rejection;
- optional trust-policy and transparency verification;
- JSON audit artifact;
- Windows bootstrap and recovery commands;
- no assertion of external-machine success without an externally generated report.

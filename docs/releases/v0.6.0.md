# AEGIS Platform v0.6.0

## Governed Runtime API and Demonstration Surface

This release exposes the end-to-end governed runtime through `POST /governed-runtime` and adds a separate dashboard demonstration surface.

The API requires an explicit canonical capability selection. Platform does not infer capability authority, create approval grants, bypass pauses or denials, or claim that simulated completion proves a real-world effect.

The demonstration surface is intentionally labeled. It creates an explicit demo selection from the visible analysis result, then displays authority, execution, validation, and reconciliation outcomes independently.

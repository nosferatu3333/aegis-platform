# v0.2.0 — Dashboard MVP

## Release identity

- **Tag:** `v0.2.0-dashboard-mvp`

- **Date:** 2026-07-26

## Objective

Make the existing mission-analysis pipeline visible and usable from a minimal
browser interface.

## Delivered

- Dashboard served by `GET /`.
- Mission input and **Analyze Mission** control.
- Intent, capabilities, selected profile, metrics, and workflow rendering.
- Raw JSON display and explicit non-execution notice.
- Dashboard delivery and research-flow tests.

## Architecture impact

FastAPI became both API host and static dashboard host. The browser called the
same `/analyze-task` contract used by API clients; no duplicate analysis logic
was added to JavaScript.

## Verification

The tagged tree includes dashboard response and end-to-end analysis-flow tests
alongside the v0.1.0 API/pipeline coverage. Git does not store a numeric test
run for this tag.

## Known limitations

The displayed workflow was proposed only. There was no execution request,
receipt, step lifecycle, or external action.

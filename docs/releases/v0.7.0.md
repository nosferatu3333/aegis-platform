# AEGIS Platform v0.7.0 — Governed Runtime MVP

## Release status

**Accepted MVP release.** This release formalizes the governed demonstration chain completed through WO-MVP-011 and accepted under WO-MVP-012.

## Product boundary

The release provides a visible and testable governed runtime:

```text
canonical capability selection
→ bounded planning
→ authority gating
→ deterministic simulated execution
→ conformance validation
→ evidence reconciliation
→ result and cognitive trace
```

It does not perform external actions and does not claim that simulated completion proves real-world effects.

## Acceptance evidence

The formal release requires all of the following:

- environment diagnostics report `ready`;
- repository validation passes;
- the complete automated test suite passes;
- deterministic governed scenarios produce `analyzed`, `completed`, `paused`, `denied`, and `failed` outcomes;
- the Git worktree is clean;
- the release commit is annotated with tag `v0.7.0`.

Run the governed scenario acceptance check with:

```powershell
python scripts/release_acceptance.py
```

## Compatibility

- Python: `>=3.11`
- AEGIS Core: `>=0.3.0,<0.4.0`
- Platform: `0.7.0`
- Execution mode: deterministic simulation only

## Installation

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python scripts/bootstrap.py --core-path "C:\path\to\aegis-core"
```

## Startup

```powershell
python -m aegis_os doctor
python -m aegis_os serve
```

Dashboard: `http://127.0.0.1:8000/`

## Rollback

Stop the server, preserve diagnostics and the failing commit, check out the preceding accepted tag/archive, recreate the environment, rerun bootstrap and validation, then restart only after diagnostics and tests pass.

# AEGIS Platform 1.0.0

WO-MVP-015 adds Ed25519 release signing and detached provenance attestations.

- deterministic distribution bundles remain unchanged;
- invalid bundles cannot be signed;
- attestations bind bundle SHA-256, size, source commit, source tree, source branch, version, and signer key ID;
- verification detects bundle, attestation, signature, and public-key substitution;
- private signing keys are never packaged.

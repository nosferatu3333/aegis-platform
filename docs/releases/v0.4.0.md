## Objective

Measure capability and consistency separately from implementation correctness,
without duplicating the AEGIS lifecycle or introducing subjective grading.

## Delivered

- Separate `aegis_benchmark` package and contracts.
- Standard-library JSON loader with deterministic ordering and validation.
- Runner reusing the production pipeline, adapter, and simulated engine.
- Exact evaluator, scoring metrics, JSON/Markdown reports, and CLI.
- Four external mission files and a documentation JSON Schema.
- 17 enabled cases and one disabled future example.
- 21 focused benchmark tests and shared pipeline composition helper.

## Architecture impact

The benchmark layer observes the existing lifecycle through public contracts.
It does not import the FastAPI application or reproduce intent, matching,
workflow, or execution algorithms. See
[benchmark architecture](../architecture/benchmark-suite.md) and
[ADR-003](../adr/ADR-003-benchmark-suite.md).

## Verification

## Known limitations

Small curated dataset, exact comparisons, simulated outputs, and no semantic
quality judging, historical trends, dashboard, parallelism, or load testing.

# v0.1.0 — Backend MVP

## Release identity

- **Tag:** `v0.1.0-backend-mvp`
- **Commit:** `037b1038a907b09074f1c65a732668be11d1bdc4`
- **Date:** 2026-07-26
- **Status:** Completed historical milestone

## Objective

Create one product-facing, deterministic mission-analysis path and expose it
through FastAPI.

## Delivered

- Pipeline contracts for intent, capability match, workflow, and result.
- Rule-based intent, complexity, and risk analysis.
- Registry/matcher adapter and real Research/Analysis profile selection.
- Deterministic workflow generation.
- `POST /analyze-task`.
- API and pipeline tests.

## Architecture impact

The release introduced the operational spine documented in the
[cognitive pipeline](../architecture/cognitive-pipeline.md). It existed beside,
not as a replacement for, the legacy cognitive orchestrator.

## Verification

The tagged tree contains tests for structured results, serialization, empty
tasks, registry selection, valid API requests, and invalid bodies. Git history
does not record a numeric test result for this tag.

## Known limitations

No dashboard, execution, policy enforcement, persistent request history, or
external research. Classification and matching were deterministic heuristics.

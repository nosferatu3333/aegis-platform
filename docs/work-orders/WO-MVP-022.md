# WO-MVP-022 — External MVP Release Candidate

## Objective

Freeze, package, sign, and verify the cumulative AEGIS Platform MVP for an external demonstration without expanding cognitive scope.

## Acceptance

- one command builds the complete release-candidate evidence directory;
- source distribution is reproducible and verified;
- provenance attestation is signed with Ed25519;
- signer is trusted through an explicit policy;
- publication is recorded in a hash-chained transparency ledger;
- trust verdict is `TRUSTED`;
- five governed acceptance scenarios pass;
- private signing material is never copied into the release directory;
- demonstration claims remain bounded to deterministic simulation.

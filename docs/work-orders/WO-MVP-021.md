# WO-MVP-021 — Demonstration Workflow and Dashboard Refinement

## Objective

Present the existing governed runtime as one coherent, externally demonstrable operator journey without expanding cognitive or execution scope.

## Acceptance flow

Request → live OPS capability selection → bounded plan → authority decision → deterministic execution → evidence → reconciliation → operator verdict.

## Boundaries

- No autonomous real-world side effects.
- No inferred approval.
- Approval-required missions pause without a canonical grant.
- Dashboard verdicts summarize, but do not replace, canonical JSON evidence.

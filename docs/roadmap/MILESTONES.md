# Milestone matrix

Future rows are proposals. “Completed” describes repository milestones, not
production readiness.

| Version | Status | Central question | Primary capability | Validation evidence | Known boundary |
|---|---|---|---|---|---|
| Phase 2.5 | Completed | Can prototype boundaries be stabilized and characterized? | Explicit legacy simulation boundaries | Tagged code and characterization tests | No product API |
| v0.1.0 | Completed | Can one mission traverse a stable backend pipeline? | Analysis API and structured result | API/pipeline tests | No dashboard or execution |
| v0.2.0 | Completed | Can users inspect the pipeline from a browser? | Dashboard MVP | Dashboard and API-flow tests | Workflow display only |
| v0.3.0 | Completed | Can execution semantics exist safely before tools? | Simulated engine and receipt | Execution/API tests | No real action or policy engine |
| v0.4.0 | Completed | Is lifecycle behavior capable and consistent on declared cases? | Deterministic benchmark suite | 53 tests; 17/17 benchmark cases | Small exact-match dataset |
| v0.5.0 | Next | Can every future external interaction cross one governed boundary? | Environment Interaction Layer — Simulation First | Proposed contract, policy-interception, registry, receipt, and simulation benchmarks | No real adapters or external actions |
| v0.6.0 | Planned | Can cross-run state be durable, scoped, and attributable? | Persistent memory | Proposed persistence/isolation tests | No autonomous learning |
| v0.7.0 | Planned | Can lessons be promoted only from sufficient evidence? | Reflection and learning | Proposed evidence/promotion tests | No opaque self-modification |
| v0.8.0 | Planned | Can multiple roles collaborate within bounded workflows? | Multi-agent collaboration | Proposed delegation/failure tests | No unconstrained teams |
| v0.9.0 | Planned | Can policy be enforced consistently across all actions? | Governance/policy engine | Proposed policy-matrix and audit tests | No certification claims |
| v1.0.0 | Exploratory | Can proven subsystems form one supportable MVP? | Integrated cognitive OS boundary | Proposed end-to-end/security baseline | Not guaranteed or production-ready |
